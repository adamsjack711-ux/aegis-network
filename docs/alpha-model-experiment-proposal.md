## Provisional experiment interface

`AlphaModelExperiment.proposal-v1` is a non-network record for architecture review. It binds the exact clean source pin; immutable V01–V12 and visible36 corpus digests; source-byte projection algorithm; baseline evaluator digest; candidate provider adapter digest; ordered case IDs; fixed then seeded-shuffled schedule; prompt/template and response schema digests; model/endpoint identifier; token, byte, call, concurrency, time and total billed-USD ceilings; data-export classification; credential reference; cancellation and uncertain-billing behavior; and an independent semantic-adjudication plan. A caller may inspect this record, but cannot activate it by writing `approved=true` or supplying a token.

Activation requires a **separately authorized, out-of-band local operator capability** bound to the exact experiment digest, endpoint, model, export bytes and maximum bill. The local broker must authenticate the operator, enforce one use and expiry, preserve a durable consumption/audit record, and reject replay or a changed manifest. Credential custody and the actual billable-cost oracle must be independently reviewed. If either the capability, budget stop or billing oracle is missing, the provider is not constructed and all model units are marked skipped. A self-authored JSON approval file or environment variable alone is not authorization. This authority is only for a research expense and data export; it cannot approve a mitigation or sign Evidence.

The proposed `ModelProvider` receives only a bounded canonical input projection: exact synthetic advisory source bytes or their predeclared excerpts, source IDs and asset identity needed for the case. It receives no gold label, local secret, filesystem path, private key, token in prompt, network target or enforcement plan. The transport, if later approved, pins HTTPS destination and certificate policy, disables redirects and proxy inheritance, bounds input/output bytes and token counts, uses one in-flight call per capability, and fails closed on timeout or ambiguous response. Retrying an uncertain billed call needs a new reconciled capability; automatic retry cannot exceed the hard spend ceiling. Exact provider API details and ceilings remain **unapproved** until Main and independent VAL review.

`ResearchHypothesis.proposal-v1` is untrusted data: `case_id`, raw outcome (`affected`, `unaffected`, `unknown`), attempted factual points (`version`, `impact`, `fix`), source IDs, claimed byte spans/quotes, uncertainty, response digest, provider/model/prompt IDs, latency and usage metadata. Unknown fields, duplicate JSON keys, excessive nesting/bytes or missing citations are rejected. A cited source ID or matching phrase proves neither publisher identity nor semantic truth. A deterministic local checker reopens the sealed source bytes, validates exact digest/span/quote and product/ecosystem/version association, then independently adjudicated humans or fixtures score each factual point for semantic support. Unsupported, withdrawn, contradicted, stale and prompt-injected points remain **non-reportable**, with all attempted points counted. The evaluator never converts this record into `SignedFinding`, a verifier attestation, local approval, T4/T5 status or a protected writer request.

## Frozen comparison and reporting

Use identical V01–V12 source bytes for deterministic and model arms: 12 cases × three fixed-order repeats × three seeded-shuffled repeats = **72 case-attempts per arm, 144 total** if a real model is separately authorized. The visible36 corpus is reported separately, never pooled with V or called blind. Preserve original case IDs and every timeout, invalid response, abstention and inconclusive epoch case in denominators. Report `planned, attempted, eligible, completed, correct, false_affected, unsupported_reportable_points, abstained, failed, skipped`, plus per-point attempted/emitted/byte-verified/semantically adjudicated/unsupported. p50/p95/p99/max latency must use one-process monotonic spans or documented cross-process clock error; three repeats are descriptive. Report CPU/GPU/RSS, actual provider tokens and **billed USD from an independent billing oracle**, not an estimate called cost. No model advantage is claimed from mock/scripted outputs or a corpus whose labels were visible during development.

Independent negative controls must cover forged self-consistent advisory bytes, quote substitution, wrong product/ecosystem, unsupported Debian epoch/backport, withdrawn/expired/contradictory source, prompt injection, fabricated impact/fix, malformed/oversized response, timeout, network denial, stale/replayed local capability, over-budget usage, uncertain billing and attempted authority promotion. Original 6/7 unsupported-positive evidence stays retained. Passing a source-byte check is not semantic adjudication.
