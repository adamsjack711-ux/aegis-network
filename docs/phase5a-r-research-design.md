## Specific gaps

1. **Ecosystem version semantics.** The private text evaluator compares dotted numeric components and abstains on Debian epoch syntax. `H11-epoch-boundary` and `P02-debian-epoch-fixed` need a reviewed, pinned Debian version comparator, including epoch and Debian revision rules. Prerelease handling must follow the relevant package ecosystem rather than generic string ordering. Until verified, return inconclusive or unknown; do not count these cases as a false affected claim or silently drop them from the planned denominator.
2. **Source and claim binding.** `ResearchResult.v2` verifies internal fields with an unkeyed digest; it does not authenticate source bytes across processes. The text evaluator verifies sealed fixture bytes, then uses a narrow regex parser. Its scripted point guard checks that a cited text lacks the remote-execution phrase. Presence of that phrase would still not establish the same product, version, polarity, asserted effect or source freshness. A supported point needs an atomic claim type, exact source digest and locator, independently checked product identity, ecosystem-specific version predicate, affirmed effect, and status. Negations, quoted instructions, unrelated products, source revisions, withdrawals and contradictory notices must remain unsupported or unknown. Model prose stays in a raw hypothesis field with `support=unchecked` until an independent adjudicator accepts each atomic claim.
3. **Authority.** Synthetic `vendor` and `registry` roles are labels in fixture data. They confer no real advisory authentication. Research checks cannot become `SignedFinding 1.0`, verifier attestations, Evidence status, local approval or protected-writer authorization. Native T4/T5 remains authoritative.

## Proposed post-freeze private work

- Add a comparator adapter selected by explicit ecosystem and version scheme. First accept only a pinned, independently tested Debian implementation for the two epoch cases. Preserve `unknown` for unsupported syntax or missing source-to-binary mapping. VAL-R owns a separate oracle with boundary, epoch, revision, prerelease, withdrawal and contradiction controls.
- Add a typed, private source-claim record: `source_digest`, `source_locator`, `source_identity`, `product_identity`, `version_predicate`, `claim_polarity`, `effect_type`, `source_status`, `retrieved_at` and `check_reason`. Build it only from digest-checked immutable source bytes. Keep free text as quoted source data. Report claim coverage, adjudicated support, abstentions and unsupported positives using **all attempted and emitted positive points** as explicit denominators. Do not turn a citation ID or phrase match into semantic support.
- Keep the deterministic and scripted arms on identical pinned inputs. Add a fresh validator-held corpus for generalization after implementation is frozen. Maintain separate reports for the independent `V01–V12` holdout, the label-visible 36 and any new hidden cases. Score all twelve V cases without removing abstentions, and report confusion counts and coverage separately. Report case failures, errors, skips and unmappable cases by ID and reason. The prior scripted response remains a guard test only.

## Reproducible real-model experiment design, disabled

No endpoint, local model artifact, credential reference, data-export permission, inference runtime or cost oracle is enrolled. The real-model arm must report `skipped` and leave billed tokens, USD cost, inference p50/p95/p99 and model advantage unmeasured. A later experiment requires separate authorization of the exact model artifact digest and license, host/runtime, synthetic input boundary, permitted local files or endpoint, credential custody if applicable, and a CPU/GPU or billing cost oracle. No real host identity, token or private key enters prompts or logs.

After authorization, run the model in an isolated local process with no writer or broker capability, a hard parent-enforced deadline and kill, CPU/GPU and memory caps, input/output byte and token budgets, maximum one in-flight request, bounded retries and no network unless an exact endpoint is separately approved. Validate strict JSON before interpreting output. Run the deterministic arm on the same source bytes and case order, then at least three model repeats in that order and a predeclared shuffled order with fixed seeds and a cold/warm split. Record per-case elapsed monotonic wall time, process CPU/GPU time, peak RSS, input/output tokens, billing evidence or local compute cost, failures and censoring. Freeze prompts, model digest, parser, source corpus, labels and scoring code before the first call. Independent reviewers adjudicate **every attempted and emitted factual sentence and positive point** against exact source bytes without seeing the model's self-assessed confidence. A source ID alone is never support. Any comparison of benefit must state the full twelve-case V denominator, confusion counts, coverage, false positives, abstentions, uncertainty and costs; the visible 36 cannot rescue a failed blind holdout. Model output remains read-only research regardless of score.
