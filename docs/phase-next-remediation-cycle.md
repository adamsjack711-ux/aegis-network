## Frozen authority and required contract decisions

1. `Finding.schema_version="1.0"`, `SignedFinding` Ed25519 canonical bytes, `InventoryItem(purl, version)` exact matching, revocation semantics and native T4/T5 authority remain unchanged. A signature proves origin and integrity, not claim truth or permission to write. Any authoritative change requires a versioned proposal, old/new reader tests, golden signatures, revocation and denial preservation, and independent security review. [Authority map](phase5-schema-authority.md).
2. 5A research output is provisional and informational. A conclusive model claim needs source entailment for the exact product, version and asserted effect; a matching fact ID alone is insufficient. Unsupported positive claims must be marked `needs-evidence` or equivalent inconclusive support disposition, with raw prose explicitly unverified. This private disposition must not silently change `SignedFinding 1.0`, create verifier attestations or grant local authority. The 5A owner must propose exact fields, migration and old-reader behavior before changing the private output.
3. 5B may evolve its provisional observation output with a separately versioned field such as `independent_status=unknown` and a machine-readable reason. `claim_status=current` means only that a locally supplied signed event is temporally current; `matched` means exact local package equality. Neither establishes a complete, fresh T4/T5 Evidence status. Unknown remains explicit absent an independently verified status proof. The owner must specify old/new JSON reader behavior. Persistent identity requires explicit `--state-dir` or equivalent opt-in; default observation commands must write no local state, including error paths.
4. 4F must propose generation-bound JetStream ACK/cursor rules before any durable cursor format or shared transport contract changes. An ACK is not an independent witnessed inclusion or local durable denial. Cursor advance requires the current authenticated owner/generation and committed local decision; stale or partitioned owners cannot erase replay obligations. Positive writer authority still requires exact current local approval, target generation, Evidence cut and native T4/T5 status in the same protected transaction. No change may weaken the inherited five-second all-agent withdrawal gate.

## Exact independent acceptance tests

**5A claim support.** Replay the retained `ai-5a-security.json` unsupported-positive arm against the exact clean candidate and require no supported positive research conclusion for its invented affected-version/remote-execution prose. Assert all unsupported prose remains labeled unverified, no `SignedFinding`/Evidence/attestation/local approval can be emitted, no network call occurs, and the old signed golden vectors remain byte-identical. Score the frozen independent holdout and deterministic baseline with per-case counts; no model advantage claim without a real enrolled model and measured cost.

**5B observer purity.** On an unprivileged, offline Linux fixture with read-only root and writable scratch, snapshot the filesystem before and after every default `status`, `inventory`, `findings` and supported observation command, including malformed, unsupported, missing-input and `--json` failure paths. Require zero unrequested writes under XDG/HOME/tmp and no network, privilege or protected-writer calls. With explicit state opt-in, require all writes stay inside the requested directory and reject unsafe path/symlink behavior. Recheck valid, expired, revoked, unsigned and malformed `SignedFinding 1.0`, exact inventory match, aliases/ranges/partial inventory as unknown, and machine-readable `independent_status=unknown` when no current independent proof is supplied. Run source and wheel installation in a pinned non-root Debian fixture; report Ubuntu and syscall tracing separately if unavailable. Retain the original `cli-5b-linux-default-state.txt` and signed-current ambiguity result.

**4F withdrawal recovery.** Replay both retained exact-pin pre-intake SIGKILL plus broker-restart trials (30.610 and 30.710 seconds) with six ordinary outbox rows pending. Instrument monotonic stage times for submit, DB commit, outbox dispatch, broker availability, agent receipt, local trust/revocation evaluation, committed durable denial and ACK/cursor advance; across processes correlate stable event IDs and use wall timestamps only with measured clock-offset bounds. Run at least three fresh trials per fault arm and healthy controls, with explicit eligible-agent denominators and all-agent coverage. Each eligible agent must commit denial within five seconds of withdrawal submission on the specified connected/recovered topology; neither a broker ACK nor a preexisting target hold is counted as new withdrawal delivery. Inject lost ACK, duplicate/reordered events, stale ownership transfer, partition/rejoin and restart. Independently read durable audit/target state before observer traffic. Require no false cursor advance, no stale-owner write, no reopening, no duplicate logical decision and full local regression. Keep any physical multi-host claim open until enrolled hosts and credentials are supplied.

## Prioritized intake

1. Validator freezes and hashes the original failures and oracles before candidate implementation review. Owners may inspect and propose interfaces meanwhile.
2. 4F instruments the 30-second path and submits any ACK/cursor contract proposal; integration lead reviews it against T4/T5 and 5-second semantics. 5A and 5B independently propose private output changes and fix only their owned branches.
3. Validator evaluates each clean exact-pin candidate against retained and new negative tests. Failed or inconclusive gates remain visible; 5A and 5B stay outside integration until their independent gates pass.
4. Integrate reviewed 4F first, then independently gated 5A, then 5B, each as a separate commit in a new isolated candidate with full regression after each intake. Recheck shared golden signatures, revocation and denial behavior. Do not merge master or activate distributed autonomous enforcement.

The 5-second all-agent gate is a **reproduced failure**, not an unmeasured target. The 5A read-only research and 5B observation-only alpha gates are **NO-GO** until their independent failures close. Multi-host ownership, external history anchors, positive recovery and distributed enforcement remain separate release blockers.
