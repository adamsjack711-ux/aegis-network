## Independent observations

The original failure corpus was copied and SHA-256 checked before inspecting next-cycle fixes. [Manifest](../benchmarks/phase-next-alpha-validation/original-copies-manifest.json) and [check file](../benchmarks/phase-next-alpha-validation/original.sha256) cover 14 exact originals, including source scripts. The new 12-case AI corpus was sealed at SHA-256 `d7a728ba657920e6adffbf26004c39fccaefa16ab55053df5a399692113c2f5f`. The [findings register](phase-next-alpha-findings.md) distinguishes retained failures from new diagnostic passes.

**Withdrawal.** Three fresh clean-baseline SIGKILL-before-intake trials plus one fresh exact `aec828d` candidate trial each had one agent and two targeted withdrawals. The baseline covered six of six eligible pairs, all finally durably denied, but conservative admission-to-denial lower bounds from worker commit timing were 30.548–30.587 s. The candidate's two lower bounds were 30.550 and 30.555 s. VAL-D's separate read-only SQLite poller then reran the clean candidate: both exact denials were still **absent 30,559.741 ms after broker restart request** and first present at 30,585.717 ms. Signed withdrawals were durably admitted before that restart request. This directly fails the five-second durable-denial ceiling with an independent committed-state read. The legacy runs have final independent readback but no timed polling. ACK and cursor progress were not treated as denials. A matched agent-alive broker restart durably denied both pairs in 1.719 and 1.702 s from submission. The driver queued four ordinary findings per trial and could not satisfy the frozen 1,000-row backlog arm; no physical protected target or independently administered multi-host witness was present. Fleet and target assertions remain unobserved. [Baseline score](../benchmarks/phase-next-alpha-validation/withdrawal-baseline-score.json) · [candidate read-only poll score](../benchmarks/phase-next-alpha-validation/withdrawal-kv-independent-poll-score.json).

**Native protected state.** The independent one-host loopback harness read committed SQLite before post-fault requests and scored **9/9 pass**: idle/monitored ownership and Evidence cuts, prepared-route ownership race, stale approval, interrupted transaction, revoked Evidence and stale Trust. It checked all nine declared routes and restart holds where applicable. No partitioned physical writer or generation-bound broker ACK/cursor was included. [Raw and score](../benchmarks/phase-next-alpha-validation/native-baseline-score.json).

**CLI.** Original retained Linux oracle rescored **8 pass, 1 fail** for implicit identity state. At integrated `3bfd2ab`, a cached offline Kali image ran UID 65534, read-only root and no network. Four default commands created no files; explicit state wrote only the named identity file. Signed-status and API guards scored **11/11 pass** with `independent_status=unknown`. Nine synthetic resource runs completed below budget, but used a mounted Debian `os-release` on Kali. The baseline omits the console entry point and offline Hatchling was uncached. At exact candidate `0df40c9`, VAL-D built the committed Git archive twice offline: both wheel bytes had SHA-256 `0e4a815ad95f5fab9d8bb997bec4ea8f67896460db86bb838441ca7318cbd0fa` and contained `aegis = aegis.cli:main`. In cached real Debian 13/Python 3.12, the installed console ran as UID 1000 with read-only root/network disabled: **six** default or failure commands made zero created/modified files, including a signed current Finding whose `publisher_authenticity=verified`, `software_match=unmatched` against the real image, and `independent_status=overall_assessment=unknown`. Explicit state made only a 0700 directory and 0600 identity, and uninstall removed its entry point and dist-info. Nine installed-wheel resource runs at 100/10,000/100,000 synthetic rows passed; 100,000-row maxima were 654.643 ms wall, 649.064 ms CPU and at least 94,756 KiB RSS. An independent Ubuntu 24.04 install could not start because the cached image lacked `ensurepip`/`python3.12-venv`; the owner's dependency-export workaround is not counted as an independent install. Python 3.13, syscall attempts and malformed-input resource budget are unverified. [Baseline score](../benchmarks/phase-next-alpha-validation/cli-baseline-score.json) · [candidate package score](../benchmarks/phase-next-alpha-validation/cli-candidate-package-score.json).

**AI.** The original seven scripted security cases reproduced **6 pass, 1 fail** at `e3da3876df413f080095dc7568a664f75ffba5b6`: an unsupported affected claim was accepted. The clean integrated v2 research guard passed **12/12 scripted challenges**, preserving an unchecked raw hypothesis and reportable unknown. VAL-D's new independent 12-case holdout gave its simple deterministic parser **11/12** exact decisions, six of six expected unknowns correctly abstained, one conservative extra unknown for the Debian epoch comparator, zero false affected outcomes, zero emitted factual prose and no prompt-injection obedience. Median/p95/max local subprocess latency: 27.472/28.796/29.540 ms. The clean `99e8664` candidate's separate 36-case, label-visible offline evaluator ran three repeats; each had 34 evaluable decisions, 33 deterministic exact and 24 scripted-check exact. Its fixed scripted provider attempted 36 unsupported positive points per trial and emitted zero reportable points; conditional claim-support accuracy is undefined because the emitted denominator is zero. The raw scripted decisions had 29 false affected outcomes per trial, and the guard reduced these to zero by abstaining. That is a guardrail diagnostic, **not** real-model performance or an independent held-out score. No real-model output, billed usage, or model prompt-order repeats exist; model cost is unmeasured, not zero. [VAL-D holdout raw](../benchmarks/phase-next-alpha-validation/ai-holdout-deterministic.json) · [score](../benchmarks/phase-next-alpha-validation/ai-holdout-score.json) · [candidate scripted raw](../benchmarks/phase-next-alpha-validation/ai-candidate-scripted-eval.json).
