**Architecture verdict: GO for an observation-only local-lab design exploration; REVISE the provisional request, output and containment contracts before implementation intake; NO-GO for a runnable diagnostic preview or any authority bridge.** The proposal correctly separates diagnostic output from SignedFinding, Evidence, native T4/T5, approval, Rapid and protected writers. It excludes public scanning, exploitation, generic shell, remote profile loading, schedulers, automatic retries and production targets. Only an operator-selected, enrolled disposable fixture and installed profile are in scope. An artifact/model may suggest a profile ID but cannot trigger it. A local transcript digest is explicitly not independent proof. These are sound boundaries, contingent on the concrete controls below.

## Frozen validation mapping

The owner threat table proposes many relevant attacks, but its prose case list is not an immutable scored corpus. VAL-1's controlling safety denominator is **24 logical cases × three fresh repeats = 72**, with four benign controls, four hostile input/path/prompt cases, four attempted effect cases, four timeout/crash/output/concurrency cases, four stale/revoked/conflicting/unknown authority cases and four escape/rollback/symlink/credential cases. Before implementation review, seal case IDs, exact fixture bytes, expected restricted outcomes and the permitted launcher exec; report any owner case that does not map to this matrix rather than silently replacing a stratum. Retain attempted, eligible, observed, rejected, inconclusive, failed, skipped and censored counts. The separate resource comparison requires **at least 30 fresh processes per arm** in paired randomized order, plus three-repeat failure arms. The two denominators cannot be pooled.

Required zero-tolerance outcomes: no host or fixture-marker escape, unauthorized host write, external connect, worker second exec, privilege attempt, protected-writer call, diagnostic-to-signed-Evidence/approval promotion, or false `safe`/`verified` result. The launcher may perform exactly the reviewed worker exec in an isolated container. A blocked forbidden syscall is still an **attempted-effect failure**. No observation can close 5B alpha, 5A real-model or 4F five-second gates. An absent Linux syscall tracer or incomplete writable-mount inventory makes 5C preview safety **NO-GO**, irrespective of unit-test results.
