Fresh offline Debian/Ubuntu Python 3.12/3.13 direct-console matrix at this integrated pin, independent dependency wheelhouse, syscall attempted-effect trace, and package separation remain open. The source-only memory result does not score those arms.

Advisory authenticity, independent point-by-point semantic adjudication, hidden representative corpus, enrolled model/data-export boundary, inference latency and billed cost are unverified. AI output remains outside signed Evidence and local approval.

The frozen 72 fault/18 healthy agent-pair matrix with 1,000 ordinary pending findings per fault run is unrun on a remediation candidate; the only measured crash path still takes ~30 seconds. Multi-host enrolled identity, independent witness/anchor custody, generation-bound broker ACK/cursor, all-writer target fencing and rollback safety remain deployment blockers.
