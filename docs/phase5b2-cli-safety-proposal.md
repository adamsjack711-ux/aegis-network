## Proposed measurement sequence after VAL-1 freeze

1. **Import and output contract.** Pin a clean exact source hash, image digest, Python minor, wheel hash if installed, and fixture/input hashes. Trace `aegis.cli -> intelligence_adapter -> config -> core` and transitive imports. Measure cold and warm import time, peak RSS and module list as diagnostics. Run fixed-time/identity JSON and human output vectors byte-for-byte against `ec939e1`, including exit codes. No source change is accepted if it alters SignedFinding 1.0 signature/grant/revocation handling or exact `(purl, version)` matching. A private v3 output or loader adapter requires a versioned proposal, old/new reader controls and Main/VAL-1 review before edit.
2. **Resource curve.** On the same reviewed **installed** wheel and real pinned Debian/Ubuntu images for both Python 3.12 and 3.13, run three fresh processes per 100, 10,000 and 100,000 synthetic installed rows, one CPU and 512 MiB hard memory. At 100,000 rows require each wall and CPU ≤5 s, peak process RSS ≤256 MiB and JSON output ≤64 MiB; three separate 256 MiB hard runs must have zero cgroup OOM kills. Report per-run exit, wall/CPU, `wait4` RSS, cgroup memory events and output bytes; p50/p95/p99 are descriptive with three samples. Compare baseline/candidate only on the same image/runtime/input/limits and warm/cold classification. Slow and closed stdout controls must finish within declared bounds without a traceback or implicit state. Do not optimize `collect_snapshot` identity hashing or package representation unless a current matched profile shows them to be the limiting stage.
3. **Default-write and syscall oracle.** Snapshot each declared writable mount before/after every default and failure invocation by path, mode, mtime, size and content digest. Run the frozen twelve logical default commands in JSON/human forms plus five signed negatives and four explicit-state controls **per distro/minor** through the generated console. Use an independently reviewed, already local Linux syscall tracer to record attempted `connect`, process execution, privilege changes and writable file operations. `--network none`, read-only root, after-tree equality and Python monkeypatch guards are supplementary controls and cannot establish the attempted-effect result. If the tracer or any required platform arm is missing, record a skip and keep alpha NO-GO; do not download a tool or borrow another distribution's libraries.
4. **Bounded input and path races.** Exercise malformed/oversized/truncated feed, grant and dpkg files, duplicate installed identity, symlink/device inputs, permission failures and concurrent replacement of `--state-dir` parent/final components. Current `state_directory` performs path checks followed by pathname operations; its race resistance is **unverified**. The trust-file path is size-checked by `stat()` before the shared `config.load_publishers()` separately reads it, leaving a potential check/read race. Reproduce safely with disposable files before proposing descriptor-relative changes. Any repair must preserve explicit state opt-in, legacy grant interpretation and default zero writes. A private read-only adapter may be considered, but moving the shared grant loader or changing publisher authorization requires a separate Main/VAL-1 contract decision.

## Safety and authority boundary

This CLI consumes only a local operator-supplied signed Mesh event file and locally pinned publisher grants. It neither fetches feeds nor contacts a broker, model, witness, target or protected writer. A verified publisher signature authenticates the source identity and scoped message, **not** the vulnerability claim. `software_match=matched` is an exact installed binary package/version identity lead; it cannot resolve source-package mapping, reachability, distribution backports or an unknown independent Evidence status. The observation output remains provisional and cannot become a local approval or mitigation command. No AI record, Diagnostic Runner result or unsigned advisory can be silently adapted into SignedFinding 1.0.
