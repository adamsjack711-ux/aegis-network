## Trial and scoring rules

- Run only on authorized disposable localhost or cached offline containers, with synthetic keys. Do not pull images, fetch advisories, contact external hosts, or enroll production credentials. An unavailable image, tracer, model, witness or comparator is **skipped**; an incomplete observation is **inconclusive**; an observed invariant violation is **fail**. Preserve first failures and later repeats separately.
- For every run record candidate commit and clean state, source and harness SHA-256, fixture and wheel digest, image ID, OS/architecture, Python version, exact command and environment, start/end monotonic times, raw stdout/stderr/exit, independent observations, and output hashes. Report planned, attempted, eligible, observed and censored denominators. A pass on one host is labeled a local laboratory result.
- A protected target passes only with a request-independent read of committed state, fence and every declared route **before** serving, health or coordinator requests. ACK, cursor, 403/503, audit text and a late observer-induced hold cannot substitute for prior durable denial. Measure time with common-host monotonic clocks or bounded polling intervals; do not subtract unsynchronized host wall clocks.
