## Universal trial rules

Use only pre-cached, disposable localhost or container fixtures, synthetic signing keys and authorized local sockets. No external host, image pull, feed, live model, real credential, production integration, public scan, exploit or protected deployment. Every run records clean source pin, harness pin/hash, fixture/image/wheel hashes, exact argv, OS/Python/architecture, trust principals, resource limits, target/event IDs, environment and dependency provenance. Raw input/output and first failing attempts remain immutable. No silent retries or post-hoc denominator changes.

For each arm report **planned, attempted, eligible, observed, passed, failed, inconclusive, skipped and censored** units with reasons. Missing cached image, reviewed wheelhouse, syscall tracer, enrolled model or independent authority is *skipped/inconclusive*, never a pass. A required skipped or censored unit keeps its release gate NO-GO. Owner-authored results are supporting evidence; an exact integrated pin needs independent challenge, cross-component negatives and full regression.

Use a same-host monotonic clock (`perf_counter_ns` or equivalent) only when its epoch is shared across those processes. A separate read-only observer reports last-absent and first-present bounds; pass a deadline only when the conservative **upper** bound is within it. For different hosts, record local spans plus independently measured clock offset/error; never subtract unsynchronized UTC clocks. UTC is for audit correlation. Publish individual values, p50/p95/p99/max and exact denominator; three trials are descriptive, not reliable tail-capacity evidence.
