## Frozen shared interfaces

`SignedFinding 1.0` canonical Ed25519 bytes, publisher identity/grants, revocation/expiry, exact `InventoryItem(purl, version)` matching, local observation `independent_status=unknown` when native proof is absent, native T4/T5 authority, exact local approval and target fencing remain unchanged. AI research has no route to Evidence, Mesh signing, local approval or protected writers. CLI default and error flows remain observation-only with zero unrequested persistent writes. No public scan, exploit, unrestricted command, production host, external feed/model/dependency download or distributed autonomous enforcement is authorized.

The grant-file check/read race is a real retained expected failure. Changing the shared loader requires an explicit versioned proposal, one bounded descriptor read, old/new golden grant and signed-event vectors, legacy and scoped grants, expiry/revocation/key rotation/duplicate behavior, and independent review before source intake. No duplicate parser may be added. Package metadata cannot silently move old lab dependencies to an extra. Model approval must be out of band; a caller-editable `approved=true` file alone is insufficient consent.

## Frozen release acceptance and sequence

VAL seals new-cycle source/fixture hashes before owner implementation review and retains the previous 44/44 original-failure manifest. CLI alpha requires four **fresh offline** Debian/Ubuntu × Python 3.12/3.13 installed-console cells, at least 84 logical command controls, two byte-identical actual wheel/sdist builds from reviewed archives, uninstall residue checks, 68 child resource/privacy trials, 100,000-row ≤256 MiB RSS and ≤5 s wall/CPU with zero OOM, zero unrequested writes and attempted-syscall tracing. Missing original dependency archives or tracer stays skipped/NO-GO. Source-only Kali or preinstalled-dependency images remain diagnostic.

The research comparison retains independent V01–V12 and separate visible36 denominators. A real model requires separately reviewed endpoint/model/prompt/schema/export/credential/billing/rate/stop authorization before any call; 72 cases per arm, 144 total, with source-point semantic adjudication, abstentions, cost and latency. Mock/scripted results cannot establish model advantage. The five-second 4F all-agent withdrawal, 72+18 pairs with 1,000 backlog, and distributed enforcement remain **NO-GO**; this alpha cycle does not weaken or silently substitute for them.
