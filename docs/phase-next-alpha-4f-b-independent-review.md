## Contract challenge before implementation

The four proposed records are useful interface sketches, but none is yet a reviewed authorization protocol. Preserve the following conditions in any versioned contract and negative tests:

1. **`VerifiedWithdrawalStatus.v1`:** distinguish witnessed *admission* from final scoped withdrawal acceptance. Define which independently administered witness and status authorities constitute acceptance, required quorum/continuity and audience, challenge freshness, expiry, revocation and contradiction precedence. A single untrusted or merely reachable witness cannot grant arbitrary withdrawal-specific denial authority. If required views are missing or conflict, report `unknown`/`conflict` and invoke only a separately authorized local uncertainty hold. The issuer grant must bind event digest, exact finding/Evidence digest and revocation scope. A coordinator-controlled HTTP receipt, Mesh signature, cached positive status or broker cursor cannot satisfy this proof. Test a valid witness acceptance withheld by a malicious coordinator and a forged or out-of-scope withdrawal.
2. **`TargetDenialCommit.v1`:** bind proof, exact plan, local approval context, target identity, owner generation, current fence and earliest expiry to the **same target transaction** as every protected writer. The denial-specific reason must be distinguishable from a generic uncertainty quarantine; neither may create a positive capability. Preserve a durable prior restriction across process restart, broker partition and restored snapshots. Expiry must close new positive authority; it must not automatically reopen a known vulnerable route. The target store needs an independent rollback anchor before a restored stale snapshot can claim a lower fence.
3. **`DeliveryEpoch.v1`:** define authenticated broker/session identity, stable event ID, target generation, consumer epoch and local denial commit ID as a cursor compare-and-swap invariant. A lost or late ACK from an old owner must never advance the successor cursor; ACK only after durable exact denial, then replay is idempotent after ACK loss. An ACK is receipt telemetry, not Trust acceptance. Test old-session ACK after successor transfer, restored cursor, duplicate/reordered withdrawal and ordinary backlog starvation.
4. **`OwnerTransferBarrier.v1`:** the writer roster and generation floor must originate from an enrolled target/operator authority, not the potentially malicious coordinator. The target must reject stale signed commands inside every protected transaction, including after partition healing. A dead local PID, expired broker KV lease or successor's self-report does not prove all writers fenced. Missing any writer, target, ACK lane or T4/T5 continuity proof keeps positive authority closed. Cross-store and cross-host atomicity is unresolved; require an explicit crash/restart state machine and fail-closed recovery tests, not an assumed global transaction.

Native T4/T5 remains authoritative. These proposed records do not authorize direct Mesh-to-enforcement promotion, early KV deletion/TTL reduction, or protected writes based on a valid signature alone. Unknown status may justify a policy-defined restrictive hold, but must never be labeled a verified withdrawal. A compromised coordinator must be unable to make a false positive status current or to silently suppress a witnessed withdrawal and preserve new authority.

## Decision and open proof

**GO for retaining the diagnostic and reviewing the protocol as a proposal. NO-GO for Phase 4F five-second release, shared-contract adoption, multi-agent protection claims and distributed autonomous enforcement.** The measured dry-run denial misses 5,000 ms by more than 25 seconds, the native T4/T5-to-target transaction binding is unimplemented, and the full frozen matrix has no evaluable trial. A successor implementation must first obtain reviewed authority semantics and then run all 72 fault pairs and 18 controls on one exact pin, with skipped/censored counts and physical target-state proofs reported separately. Multi-host identity, independent witness custody and rollback anchoring remain open gates.
