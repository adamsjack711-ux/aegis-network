## Universal trial discipline

2. Each fresh trial starts with independent state and declared fault schedule. Retain the first failed run when a retry passes. Compare baseline and candidate only under the same source inputs, image, limits, warm/cold classification and clock method. An owner-authored focused suite is supporting evidence, not the independent gate. Run full regression and cross-component negatives on the exact integrated commit before release consideration.
3. Use a same-host monotonic clock (`perf_counter_ns` or equivalent) for controller/agent stage differences only when that OS guarantees a shared clock. Read-only independent polling reports last-absent/first-present intervals; pass only when the **conservative upper bound** is within the deadline. For separate hosts, record local spans and an independently measured offset/error bound; never subtract unsynchronized wall clocks. UTC is for correlation, not latency proof. Report p50/p95/p99, maximum and every missed pair; an aggregate percentile never hides a five-second all-agent miss.

Every agent enrolled and in withdrawal scope before admission remains in the denominator, including a crashed/disconnected one. Independently read every target's restrictive state and designated protected route **before observer traffic**, during fault and after recovery. A dry-run SQLite denial alone does not establish a protected target hold. The all-agent gate needs all 72 targeted pairs and all 18 controls observed with zero missing eligible agents, zero unauthorized positive writes, zero lost withdrawal/replay obligations, one logical denial per target-event, and conservative ≤5,000 ms upper bounds for **both** mandatory clocks for every eligible fault pair. For any serializer change, fix time/identity in a deterministic fixture and require **byte-for-byte stdout equivalence** to the reviewed baseline for the same input (including field order, whitespace and newline), or submit a versioned private output-contract change before scoring.
