2. **Inert contract fixtures only:** under `tests/recovery_phase4f1/**`, model signed source bytes, native witness obligation/floor and canonical agent audit transactions with disposable local data. No target mutation or broker ACK. The fake authority must be explicitly named `inert` and cannot be imported by production source. Compare complete/fresh versus fresh-signed-old head, anchor floor rollback, withheld page and source mismatch. These are falsification tests, **not native T4/T5 validation**.
3. **After Main and VAL-1 versioned-contract approval:** implement only in separately reviewed native source commits, then rerun focused contract/adversarial tests and the frozen 72+18 matrix. The ownership of journal/agent/target source is outside this lane's present permission. Any required endpoint/schema/authority change returns to architecture review first.
4. **Independent exact-pin review:** VAL-1 runs its own observer and fault schedule against the integrated clean commit, retains every raw run and compares the source/harness pins. An owner-authored pass never changes a release gate alone.

## Frozen workload and denominator

Pre-enroll **three** eligible agents and their canonical audit stores, target roster and local inventory/policy; issue **two** valid scoped withdrawals; take **three fresh repeats** of **four** arms = **72 agent-owned fault pairs**. Add **18 healthy broker-restart controls** (3 agents × 2 withdrawals × 3 repeats). Put **1,000 ordinary pending findings in every fault run**, retaining independent first/last queue IDs. Arms: (A) pre-intake SIGKILL plus broker restart; (B) broker/network partition and rejoin; (C) durable denial followed by lost ACK and replay; (D) stale old owner versus successor. Predeclare SIGKILL and partition times relative to `t_submit`; do not shorten or force-delete the 30-second KV lease. Failed launch, missing cached image, no independent anchor, unavailable witness/T5 or inaccessible canonical store is skipped/censored with reason and leaves the release gate NO-GO. No post-hoc eligibility reduction.

For each arm and control report `planned, attempted, eligible, observed, passed, failed, inconclusive, skipped, censored`, **per agent/withdrawal**, plus both latency bounds and whether target restriction held. The frozen denominator remains 72+18 even if a killed agent cannot restart or a required authority is offline. Never report a target-side proxy as an agent-owned result. The all-agent deadline, no false accepted rows, no unauthorized positive write, no lost obligation, no stale-generation win and no target reopening must all hold on one reviewed integrated pin. Resource usage and withdrawal propagation/denial latency are measured separately from protected-write confirmation.

## Current release blockers and exit criteria

The earlier 30.559-second miss is consistent with a measured broker KV claim wait; it does **not** prove that bypassing or shortening the lease is safe. This proposal leaves the lease untouched. The new native floor/obligation and agent-audit-anchor protocols, independently held custody, old-writer exclusion, authenticated multi-host identity, generation-enforced JetStream ACK, exact protected target transaction, and full regression are unproved. A fault arm with required authority outage longer than five seconds may be **impossible** under the frozen per-agent metric; keep that arm failed and seek an explicit reviewed change to the fault model rather than recasting a target hold as a pass. No external hosts or real credentials are enrolled; use disposable localhost/container fixtures and throwaway signing material only.

**Exit to implementation intake:** Main and VAL-1 approve signed record encodings, latest-floor truth source and one-witness deny-only rule; native T4/T5, agent, target and broker owners accept exact interface boundaries; an inert falsification suite fails closed for the listed negatives. **Exit to Phase 4F release:** independent exact-pin 72+18 and full regression pass with both ≤5-second bounds and zero unauthorized writes, with all custody/multi-host/rollback gates met. Neither exit is met now.
