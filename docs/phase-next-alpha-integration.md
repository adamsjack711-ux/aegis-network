## Release decisions and next gates

- **GO:** Isolated offline, read-only 5A fixture evaluation on this exact candidate. It is a research harness, not an authenticated Evidence source or real-model result. The separate frozen **AI research release remains NO-GO** because real-model accuracy, latency and billed cost are unmeasured.
- **NO-GO:** Installable 5B Linux alpha. Reconcile the packaging/grant-loader conflict, prove independent Ubuntu and Python 3.13 installs, resolve syscall/race evidence and meet the frozen 256 MiB resource envelope. The 24+8 matrix passed only with a hybrid Ubuntu dependency mount. Source-only behavior may be used in an authorized lab but is not an alpha release.
- **NO-GO:** 4F five-second withdrawal recovery and distributed autonomous enforcement. Revise the generation authority, rollback anchor, witnessed withdrawal acceptance, all-writer transfer barrier, target transaction and generation-bound ACK/cursor contract before implementation; then independently run the 72+18 matrix and separately validate multi-host identity, witness custody and restored checkpoints.
- **NO-GO:** Production integration, AI-to-authority promotion, external network/model access and master merge.

The next three engineering priorities are (1) revise and independently test the native owner-generation/withdrawal transaction protocol without reducing the five-second requirement, (2) publish a reviewed Linux packaging/grant-loader compatibility proposal and supply an independently reproducible Ubuntu runtime wheelhouse plus syscall/no-write evidence, and (3) obtain a genuinely hidden advisory corpus and an explicitly authorized bounded local-model experiment before any model-benefit claim. The 4F security blocker remains first for distributed enforcement; the 5B work may proceed independently for observation-only alpha.
