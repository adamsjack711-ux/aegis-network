## Shared-contract and operational decisions

1. **SignedFinding 1.0, exact `InventoryItem(purl, version)`, native T4/T5, local approval and target generation remain frozen.** No alternate grant parser, dependency-extras split, AI-to-Evidence path, diagnostic scheduler/remote authority or 4F protected writer is adopted here. The existing grant-file check/read race remains open and needs a single bounded descriptor read with exact parser-equivalence and old/new reader tests before any shared loader change.
2. **Offline dependency supply is not yet approved or complete.** An eligible wheelhouse must contain original actual Hatchling and platform runtime wheel archives, SHA-256, tag/ABI, license, supplier/provenance and reviewer pin, then pass `--no-index` normal resolution in four fresh disposable Linux cells. Extracted cache files, resident image packages, `--no-deps` and unreviewed downloads cannot close alpha acceptance. The present narrow package experiment skipped 2/2 builds, 4/4 installed cells and 84/84 logical cases.
3. **Linux syscall validation needs a pinned disposable tracer environment.** Record image/kernel/tracer binary and digest, seccomp/namespace/cgroup profile, complete writable-mount and FD inventory, non-root UID, exact argv, attempted connect/exec/privilege/write effects and failures. Source-tree equality and `--network none` are useful controls but do not prove absence of attempted effects. Current frozen 68 resource/privacy child cases remain unrun on the four installed cells.
4. **OpenAI evaluation remains offline.** A future real-model experiment needs separate explicit authorization for exact endpoint/model/prompt/schema, synthetic export bytes, credential custody, hard rate/token/USD stop, billing oracle, sealed independent labels and all attempted/abstained cases. A caller-editable approval file alone is insufficient; no model accuracy, latency, billed cost or benefit is claimed.
5. **4F recovery does not shorten the KV lease.** Choose/version the native deny-only anchor-equivalent versus four-view rule, prove independent rollback-resistant latest-withdrawal floor and custody, atomic admission/anchor/receipt crash recovery, canonical agent audit and old-writer exclusion, physical JetStream ACK/consumer fencing, and target-side exact approval/Trust/generation transaction. Preserve both five-second submission/admission clocks, 72+18 pairs and 1,000 backlog. Until independent success, distributed enforcement stays disabled.
6. **5C is not implementation eligible.** Pin concrete operator/enrollment, sealed fixture, seccomp/tracer/image/kernel/mount/FD and output-capability bytes; freeze 24×3 safety and 30/arm performance separately. No diagnostic code, timer, remote inbox, live host inspection or outbound sharing is accepted now.
