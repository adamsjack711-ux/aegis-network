## Offline evaluation contract proposal

1. Keep the sealed 36-case and V01–V12 manifests immutable and report them separately. Add a new validator-owned, hidden, independently labeled corpus before measuring generalization. Freeze exact source bytes, labels, eligibility rules, case IDs, manifest SHA-256, scoring code and parser pin before a candidate run. No post-hoc denominator exclusions. Author-labeled supplemental cases remain development controls.
2. Feed identical advisory bytes and identity/version inputs to deterministic and scripted arms. A future model arm receives the same permitted advisory facts, without baseline answers or labels. Freeze a prompt and output schema version. No local inventory identifiers, keys, tokens, deployment topology or protected-writer state leave the process.
3. For each case record planned, input-eligible, comparator-inconclusive, attempted, abstained, decision, expected label, exact-match, false-affected, false-unaffected, citation errors, and source-status errors. Score all attempted cases; report accuracy over eligible cases and coverage over planned cases. Preserve both counts in every summary.
4. For each point record attempt ID, raw hypothesis text, cited fact IDs, atomic claim kind, source SHA-256, exact byte locator, source role/acquisition as fixture observations, parser disposition, emitted/reportable flag and independent adjudication state. Report attempted, syntactically parsed, digest-bound, fixture-parser-consistent, emitted, independently adjudicated and unsupported-positive emitted counts separately. A source ID, citation, hash, model confidence or matching deterministic outcome alone never upgrades model prose.
5. Reopen the exact sealed source bytes at check time. Recompute decisive quote span and product, ecosystem, version, polarity, effect, freshness and withdrawal associations. Retain contradictions and unknowns; never infer safety from a withdrawn notice. Debian epoch and distribution backport claims remain abstentions until a pinned comparator and source-to-binary mapping have an independent boundary oracle. Treat synthetic `vendor`/`registry` strings as fixture labels, not authenticated advisory identity.
6. Time case execution with a monotonic clock within each process; record process CPU and peak RSS. Report per-case p50/p95/p99 and whole-run wall/CPU separately, with cold and warm runs identified. For a future provider arm separately time request preparation, network/service wait, parse, source check and scoring. No timestamp subtraction across unsynchronized hosts. Repeat at least three trials with a fixed order and seeded permutation; disclose cache and retry behavior.

### Required negative controls

- Re-run the original F1 unsupported-positive case through the actual `research()` reader/presentation path. It must yield reportable unknown/needs-evidence, with the fabricated point only in unchecked raw hypothesis.
- Even when deterministic version matching is affected, fabricated remote-execution or other impact prose remains unchecked and absent from reportable points.
- Reject a same-source but non-decisive quote, source role/acquisition spoof, changed source bytes, product/version/polarity mismatch, unrelated effect sentence and self-consistent private-record tamper without reopened source bytes.
- Abstain on revoked, withdrawn, stale, contradictory, future-dated, unsupported comparator, missing source, package collision, conditional configuration and prompt-injection inputs. Do not let an advisory's instructions alter the checker or trigger commands.
- Exercise malformed/oversized model output, schema version mismatch, missing usage, timeout, redirect, provider error, budget exhaustion and unavailable provider. The default offline run must fail before any network attempt.

## Dormant OpenAI experiment boundary

The unmerged external branch `f4332e2` contains `OpenAIResponsesProvider` in `src/aegis/intelligence/openai_provider.py`. Read-only review found a fixed Responses URL, default `authorized=False`, one-call semaphore, 20,000 input bytes, 100–1,000 output-token request bound, 16,384 response bytes, 15-second default/30-second maximum timeout, no redirects, no tools, `store=false`, and no retries. Its tests use a stub opener. This is useful design input, **not an approved adapter or execution authority**. A caller-set boolean and locally supplied API key do not constitute an independently reviewed experiment authorization, and the implementation has no billable-cost ceiling or credential enrollment/custody mechanism. Do not copy, import, merge, construct or invoke it in this phase.

Before any external call, Main must separately approve a concrete, version-pinned endpoint and model; permitted source/export byte set and retention boundary; exact prompt, schema and input manifest hash; credential reference and custodian without exposing the secret; max input/output bytes and tokens; timeout, concurrency, request-rate, retry and total-call caps; a hard USD budget with stop behavior; actual provider usage and billing oracle; and failure logging/redaction. Independently verify that billing and rate limits cannot be bypassed by retries or incomplete usage records. No provider call or credential provisioning is authorized by this proposal. The real-model arm is **skipped**, with latency, tokens, billed cost, supported-claim accuracy and model advantage **unmeasured**.

## Acceptance and open research

VAL-1 should independently confirm the frozen original failures, exact-pin source integrity negatives, denominators, point-level unsupported-claim count and no authority path. A new blinded, source-labeled holdout and independently adjudicated atomic claims are required before claiming model benefit. A parser-consistent fixture result is not proof of a real vulnerability. The strongest unresolved research questions are authenticated advisory acquisition and status, semantic entailment beyond the narrow effect grammar, Debian epoch/backport semantics, independent point adjudication, and a reproducible real-model cost oracle. This lane is GO only for isolated offline research preparation; external inference and any enforcement authority remain NO-GO.
