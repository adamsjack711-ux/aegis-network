## Required contract revisions before authoritative runtime code

1. **Choose the deny-only appraisal rule and fault model.** Define exact approval semantics for four complete current witness views versus anchor-equivalent source when one witness withholds. In the latter case the anchor must independently authenticate the original signed source, live/historical scoped revoker grant and compromise cut, persist source bytes, and expose a complete, current, rollback-resistant floor. An unavailable, stale, equivocal or compromised anchor yields unknown/hold, never an accepted exact row. The honest, independently administered anchor and at-most-one faulty witness are explicit assumptions, not demonstrated properties. This rule cannot grant positive history or arbitrary coordinator denial.
2. **Finish the native wire and resource contract.** `NativeFloorChallenge.v1` lists requested page size **1–128**, while the proposed bounds later say **1–16**. Choose a single supported range and define negotiation/rejection. Freeze canonical signed envelope versus payload digests, Ed25519 domain bytes, response/error encoding, source size, 64-page/1,024-obligation/8 MiB limits, proof ordering and terminal completeness with positive and adversarial golden vectors. A limit overflow is unknown, not successful truncation. Define roster/epoch transition certificate bytes and how a retired/compromised grant is rechecked against the full bounded admission interval.
3. **Prove the independent latest floor and write-ahead state machine in an inert harness.** Predeclare source handoff, witness durable append, anchor durable commit, receipt and agent read times. Kill before/after each write and drop each response; recover exactly one obligation without a lower floor, false receipt or duplicate identity. Challenge fresh-signed old head, withheld latest floor, fork, partial page, replayed nonce, wrong signed source, malicious witness and coordinator suppression. Current native T4 sealed archive and 4E-C shadow views cannot substitute.
4. **Specify executable enrollment and all-writer barriers.** Bind operator identity, workload credentials, canonical SQLite store, target home and independent audit anchor to a physical host/volume custody domain; define profile-1 exclusion and restored snapshot behavior. Finish generation-bound **physical** ACK/consumer retirement and both logical cursors. At the target, establish a precise Trust freshness/cut and earliest-expiry linearization rule under the mutation/audit lock; all protected writers must reject stale signed commands and old generations. The preclaim deny path may neither ACK, move cursors nor touch the target.
5. **Keep the frozen falsification denominator.** After approved contracts and implementation, independently read each agent's own canonical `revocation_decisions`, exact tombstone and proof via a separate read-only SQLite connection. Both witnessed submission→denial and durable witness-admission→denial conservative upper bounds must be ≤5,000 ms for every eligible pair across **72 fault pairs +18 controls**, with 1,000 ordinary pending findings in every fault run. Target sentinel holds have a separate denominator. Missing agent/store/anchor/T5 view, an outage over five seconds or a restored state is missed/censored, never a proxy pass or timer reset. Report every pair, clock uncertainty, backlog, CPU/RSS, stage tails, target restriction and unauthorized-write count. Run full integrated regression only on a clean exact candidate.
