# Phase 5B-A installable observation-only Linux alpha gate

This is the integration lead's acceptance boundary aligned with VAL-D's independently [frozen oracle](../../phase-next-alpha-astra/docs/phase-next-alpha-validation-freeze.md) at `5c5d94f9c3b9ca99c29301bc743767233599ab4f`. The approved baseline `3bfd2ab` contains source-level CLI observation but withholds the installed `aegis` console entry point because independent wheel, tracing, Ubuntu and resource gates remain incomplete. [Retained failure and previous review](phase-next-remediation-candidate-review.md).

## Frozen data and authority contracts

- `SignedFinding 1.0` and its Ed25519 canonical bytes, locally pinned publisher grant, signed scoped withdrawal and exact `InventoryItem(purl, version)` are unchanged. No range/alias/backport guess becomes an exact match.
- Private `inventory-v2`, `status-v2` and observation output distinguish `publisher_authenticity`, bounded local-file claim status, exact `software_match`, and `independent_status=unknown`. Without independently verified current native T4/T5 proof, `overall_assessment` remains unknown even for a signed exact match.
- Default commands use no persistent ID or output path. `--state-dir` is explicit persistence opt-in. No CLI observation invokes a protected writer, local approval, mitigation or research-to-Finding adapter. A valid signature cannot establish vulnerability or authority.

## Required independent experiments

1. **Offline wheel and console script.** From a clean exact commit, build using a declared immutable local dependency cache with network and pulls disabled. Install/invoke/uninstall in disposable non-root Debian and Ubuntu Python 3.12+ containers, with read-only source/root, no capabilities and no new privileges. Verify console entry point, `--help`, `doctor`, `inventory`, `status`, `findings` and error exits. Pin image digest, wheel SHA-256, cache contents, command and result. Missing cached build dependencies are **skipped/incomplete**, not a pass; no network fetch is authorized.
2. **No unrequested writes.** Run the frozen minimum of two real cached distributions × twelve default commands = **24** default invocations, plus four explicit-state controls per distro = **eight** opt-in controls. Include the original implicit-state paths, signed current/expired/withdrawn, malformed feed, missing files, unsupported distribution, failed signature/grant and parse errors. Snapshot all declared writable mounts before/after with content, metadata and path inventories; require zero created/modified files. Explicit `--state-dir` may write only inside its canonical selected directory and must reject user-controlled ancestor/final symlinks and unsafe modes. Include a concurrent path-replacement arm if the fixture supports it; otherwise mark race resistance unverified.
3. **Unknown independent status.** On locally generated signed-current exact-match input, require `software_match=matched` while `independent_status=unknown` and `overall_assessment=unknown` in JSON and human text. Check expired, future, withdrawn, invalid-signature and stale/withheld status; none may imply current T4/T5 validity. Partial, duplicate and unsupported inventory stays unknown. Old v1 consumers must fail closed or migrate explicitly.
4. **Isolation.** Inspect import graph and runtime side effects. Remove or explicitly justify the transitive `cli -> adapter -> config -> core` path; any shared loader refactor requires equivalent publisher-grant tests and architecture review. A syscall-level trace, if available in the already cached lab image, must show no network, subprocess, privilege change, protected-writer connection or default write. Python monkeypatch guards alone are supporting evidence, not kernel proof. No connection or model option is enabled by default.
5. **Resource envelope.** On both pinned Linux images, repeat representative 100, 10,000 and 100,000 package inventories at least three fresh times **per distribution**. Report per-run wall time, CPU, peak RSS, output size, bounded feed/line limits, and p50/p95 where sample size permits. Publish any pass threshold before comparative scoring; otherwise the envelope is descriptive. Do not call an exploratory macOS parser timing a Linux alpha benchmark. Record every timeout, OOM, skip and unsupported distribution.

## Decision

CLI alpha GO requires every mandatory security, packaging and Linux matrix arm to pass on one clean integrated commit with independent raw evidence. A source-only GO does not clear installable alpha. The console entry point remains withheld until this gate passes. CLI alpha does not imply native mitigation or distributed-enforcement GO.
