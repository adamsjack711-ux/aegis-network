## Frozen interfaces and boundaries

`SignedFinding 1.0` canonical Ed25519 bytes/grants, `InventoryItem(purl, version)` exact match semantics, native T4/T5 authority, local exact approval, target generation fence and five-second **all-agent** durable withdrawal-denial metric remain frozen. Mesh, HTTP, broker ACK/cursor, AI research and Diagnostic Runner output cannot independently authorize a protected write. The CLI remains offline, observation-only and zero default persistent writes; absent independent T4/T5 proof is explicit `unknown`. 5A private research records and 5C diagnostic records are provisional and have no direct adapter to signed Evidence, Finding or local approval. A valid signature authenticates a publisher, not the factual claim.

Changes to authority-bearing bytes or shared reader semantics require a versioned proposal, backwards-compatibility table, golden signature/old-new reader tests, revocation and denial preservation, independent security review and a separate Main decision. A packaging dependency or publisher grant-loader move is a shared compatibility change and gets the same review before edit. No unapproved external model/feed/dependency network, image pull, external host or production deployment is allowed. Existing real credentials are excluded; disposable test signing material may be generated inside localhost/container fixtures.
