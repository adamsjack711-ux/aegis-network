The curator created these fictitious OSV inputs, labels, scripted selections and grading rules before viewing any multi-row candidate output. No live model or natural model selection is part of the experiment. Cases are constructed challenges, including a paired row permutation. The conflict rule is the conservative Aegis handoff policy, including abstention across contradictory matching rows. These cases do not estimate ecosystem prevalence.

Pass only the selected case's asset and advisory to the candidate. A format adapter may construct the expected container, canonical UTF-8 source bytes and IDs. Convert each frozen scripted pointer to the candidate's opaque ID by matching the original row, independently of the expected decision. For the unissued token, use an ID outside that request's set. Labels and scoring stay outside the request. Record any unavailable observation. Do not change labels after seeing output.

For each attempt record the scripted proposal and pointers, emitted decision and accepted pointers. Explicit refusal with no released determination counts as unknown for decision safety. If the input itself is refused, record separately that the selection path did not run for that case. Rejected or abstained selections must release zero supported pointers. Check accepted pointers against the exact source digest, JSON pointer and original bytes, with package and version verified from source. Extra rows in a supplied selection invalidate the whole selection. A contradictory global case cannot be resolved by cherry-picking one row.

Primary runs r01–r07 cover the seven distinct fixtures once. Score definitive reports against the frozen class. False affected/unaffected counts include any definitive report on a frozen unknown case. A miss is a frozen determinate case with no correct definitive report. Count abstentions/refusals separately, including expected abstentions on indeterminate cases. Controls r08–r16 deliberately inject errors or abstain. Report their expected-guard match separately, and record any determinate misses caused by a scripted selection. Report pooled results with all 16 attempts retained.

For pointer precision use correctly supported emitted pointer selections divided by all emitted pointer selections. A zero-pointer decision contributes zero to both counts. Also report scripted selection precision (matched source-support pointers / all scripted selections), separately from accepted precision and from decision polarity. For a wrong-polarity proposal the right source pointer can still earn pointer identity credit; it cannot earn decision credit. A source attribution is correct only when the bound digest, pointer and bytes match. Unissued IDs count as attempted selections. Report source coverage on the four determinate primary cases.
